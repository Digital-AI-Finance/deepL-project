# Northwind Content Factory

Generated output of a research prototype: an AI content pipeline for a regulated
fiduciary firm, built with no access to any client system.

**Northwind Fiduciary AG does not exist.** The firm, its regulatory perimeter and its
approved-claim library are synthetic. Every asset here was written by an AI agent
grounded on them, and nothing on these pages is advice of any kind, describes any real
firm, or should be relied on.

This repository holds nothing but the generated site. It is built from a private
working repository and rewritten wholesale on each publish, so its history is not
meaningful.

Pages carry a `noindex, nofollow` robots tag and `robots.txt` disallows everything, so
the site should stay out of search results. That is a request to well-behaved
crawlers, not access control: anything here is public to anyone with the link.
